Amazon Clone Website


This is a responsive Amazon Clone website built using HTML, CSS, and JavaScript. It replicates the design and functionality of Amazon's product listing, cart management, checkout, and order tracking pages.


Project Overview
The project showcases:


Frontend Development: Fully responsive design using HTML, CSS, and modern JavaScript.
Interactive Features: "Add to Cart," "Place Order," and "Order Tracking" functionalities.
Realistic UI: User-friendly and clean interface with Amazon-like appearance.
This project is designed for portfolio purposes, demonstrating core web development skills.


Features
Product Listing Page: Displays products with images, names, prices, and ratings.
Shopping Cart: Allows adding/removing items to/from the cart.
Checkout Page: Includes order summary, total calculations, and shipping options.
Order History Page: View previously placed orders.
Order Tracking: Simulated tracking feature showing the order status.


Technologies Used
HTML5: Structure of the website.
CSS3: Styling and layout (including Flexbox and Grid for responsiveness).
JavaScript (Vanilla): Dynamic content, interactivity, and DOM manipulation.


Setup and Deployment
To view the project locally:

1.Clone the Repository: git clone https://github.com/huzaifahk7/clone-amazon-website.git

2.Open the Project: Navigate to the project folder and open index.html in any browser.

cd clone-amazon-website
open index.html

3.Live Server (Optional): If you're using VS Code, install the Live Server extension for better viewing and automatic reloads.
